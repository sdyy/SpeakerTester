# 🔊 喇叭好壞測試器 (Speaker Tester)

這是一個基於 **HTML5 Web Audio API**、**Node.js Express** 與 **WebSocket** 協同開發的雙端即時聲學測試系統。

本系統分為兩個部分：
- 💻 **電腦控制端 (PC)**：負責產生高精度的測試音訊（對數掃頻、單音、粉紅/白噪聲），並以大螢幕即時渲染手機端回傳的 FFT 頻譜與喇叭品質評估報告。
- 📱 **手機接收端 (Mobile)**：負責在喇叭旁透過麥克風採集音訊，關閉所有濾波干擾以取得最真實的聲音，執行快速傅立葉變換 (FFT) 與音訊指標評估。

兩端藉由 WebSocket 達到毫秒級的同步測試，並能在完成對數掃頻後，自動產出喇叭效能指標與品質星等。

## ✨ 核心特色

1.  **聲學優化麥克風採集**：手機端調用麥克風時，強制**關閉**自動增益控制 (AGC)、回音消除 (AEC) 與降噪 (NS)，以獲取喇叭發出的無損真實波形。
2.  **高精度對齊算法**：手機端依據時間戳與對數掃頻公式 $f(t) = f_{start} \cdot (f_{end}/f_{start})^{t/D}$ 動態推算喇叭的發聲頻率，並在 FFT 頻帶中取得對應振幅，有效解決網路傳輸延遲。
3.  **多維度喇叭評級**：
    *   **低頻延伸截止點**：量測喇叭的低音下潛極限。
    *   **高頻延伸截止點**：量測高音上限。
    *   **頻域平坦度**：計算 250Hz ~ 8kHz 核心頻段的分貝標準差（標準差越小，音質越平直還原）。
    *   **諧波失真 (THD)**：估算非線性諧波能量占比。
4.  **Premium 視覺與可視化**：
    *   **Glassmorphism (毛玻璃)** 暗黑系高質感面板。
    *   PC 端使用 **Chart.js** 渲染對數座標的頻率響應圖。
    *   手機端自研 Canvas 渲染**霓虹頻譜瀑布圖**。

## 📐 聲學量測與音量校準說明

### 1. 數位分貝 (`dBFS`) 與實體分貝 (`dB SPL`)
本系統圖表與即時監測中顯示的分貝（`dB`）均為**負值**，這是因為數位音訊領域採用的是 **`dBFS` (Decibels relative to Full Scale，滿刻度分貝)**：
* **`0 dBFS`**：數位訊號的極限上限值（再往上就會產生數位破音/Clipping）。
* **`-90 ~ -10 dBFS`**：數位系統的正常工作範圍，負得越多代表聲音越小。
* 這與日常生活中所見的 **`dB SPL` (聲壓級，正值)** 不同。`dB SPL` 是相對於人類聽力極限（$20\ \mu\text{Pa}$）計算；而系統麥克風所擷取的是數位類比轉換後的數值，故以負數的 `dBFS` 表示。

### 2. 時域 `RMS` 音量計算與自動校準
為避免傳統在頻域 (`FFT Bins`) 直接平均分貝所導致的「分貝稀釋」問題（即強烈的單音被大量安靜的背景頻帶稀釋而顯得極小聲），本系統全面採用**時域 `RMS` (Root-Mean-Square，均方根)** 計算音量：
$$\text{Volume (dBFS)} = 20 \log_{10}(\text{RMS})$$
* **自動校準流程**：
  1. 電腦端發送 `1 kHz` 校準基準音。
  2. 手機端即時以 `RMS` 評估音量，若達到標準目標值 **`-48 dBFS`** 則判定校準成功。
  3. 若低於該數值，系統會發出警示要求「靠近喇叭」或調整主音量，並內建 `3.5` 秒自動超時防護。

### 3. 高精度頻率偵測
* **低頻捕獲優化**：將 `fftSize` 提升至 `4096`，並將雜訊過濾的起跳頻率下調至 `18 Hz`。這使得系統在 $48\text{ kHz}$ 取樣率下，頻率解析度提升至 $11.7\text{ Hz}$，能百分之百精確捕捉並辨識如 `50 Hz` 等極低頻率訊號，避免了舊有 `2048` FFT 帶來的頻域洩漏與頻率誤判（如將 50Hz 誤判為 70Hz）。
* **iOS 連線相容性**：針對 iOS 裝置（Safari），在獲取 `getUserMedia` 麥克風串流時關閉了系統硬體的語音前處理（`noiseSuppression: false`、`echoCancellation: false` 等），防止 iOS 自帶的通話降噪功能將低頻掃頻測試音當作噪音濾除。

## 🚀 快速啟動

### 1. 安裝環境與套件
在專案根目錄下，安裝 Node.js 依賴套件：
```bash
npm install
```

### 2. 啟動伺服器
執行以下指令啟動同步網頁與 WebSocket 伺服器：
```bash
node server.js
```
啟動後，控制台會自動偵測本機 IP 並輸出連線網址。

### 3. 開始測試
1.  **電腦端**：打開瀏覽器訪問 [http://localhost:3000/?role=pc](http://localhost:3000/?role=pc)。
2.  **手機端**：確保手機與電腦連接在 **同一個 Wi-Fi 區域網路**。掃描電腦控制台的 **QR Code** 或手動輸入 `https://<電腦IP>:3001/?role=mobile`。
    > ⚠️ **HTTPS 憑證提示**：由於手機端調用麥克風 API 強制要求 HTTPS。本系統在啟動時會自動生成 SSL 自簽憑證。當手機開啟網頁提示「您的連線不是私密連線」時，**請點選「進階」並選擇「繼續前往」**即可安全使用。
3.  **噪聲校準**：在手機端點擊「授權麥克風」，並在安靜環境下點選「校準背景噪聲」。
4.  **進行測試**：手機與電腦連線成功後，在電腦端選擇測試模式並點選「開始測試」，即時觀測量測圖表與最終診斷評語。
